🚀 v2.0 - Professional Security Release November 30, 2025

Major release transforming ZooBot into a professional platform with enterprise-grade security!

🛡️ Anti-Cheat System

  • Rate Limiting - Prevents command spam (10 commands per 5 seconds)
  • Suspicious Activity Detection - Flags unusual patterns
  • Transaction Logging - All economy actions recorded for audit
  • User Snapshots - Backup states for rollback capability

🔨 Moderation System

  • !warn @user [reason] - Issue warnings (auto-ban at 5)
  • !botban @user [reason] - Ban users from bot
  • !mute @user [duration] - Silence users temporarily
  • !clear [amount] - Delete messages
  • !modlogs - View moderation history
